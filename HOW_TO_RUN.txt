MEDIQUEUE SA — LOCAL SETUP

1. Copy the project folder into XAMPP's htdocs directory.
2. Start Apache and MySQL.
3. In phpMyAdmin, create a database named mediqueue_sa and select it.
4. Import schema.sql into the selected database.
5. Default XAMPP settings are localhost / mediqueue_sa / root / blank password.
   If your database settings differ, copy config.example.php to config.local.php
   and edit it. Never commit config.local.php to GitHub.
6. Open http://localhost/MEDIQUEUE%20FINAL%20PROJECT/ or main.php.

Import schema.sql once through phpMyAdmin. db.php does not create the database
or rerun schema changes on every request.

The Python prediction services are optional. The PHP application has fallback
logic and can run without them. To run a service locally, install its
requirements.txt and run python app.py from that service's directory.

For zero-cost shared PHP/MySQL hosting, follow DEPLOY_FREE.md.

This is a student/demo application. The model datasets are synthetic and not
clinically validated. Do not use real patient data. Never commit config.local.php
or hosting credentials.
